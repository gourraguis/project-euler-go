# Project Euler using Golang

In order to improve a little bit, thought it would be nice to solve Project Euler questions using Golang, this is my first time using Go so I might be missing better ways of doing things, I'll try to refactor solutions as I get better.
 * Most of the solutions work for different input (i.e: if PE asks for 10001th prime number, the solution can find any nth prime number).
  * Utils package contain different helpers that are used in multiple problems.
  * Most of the solutions are not optimal, I try to focus on writing simple solutions that work relatively well.
